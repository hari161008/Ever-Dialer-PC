# Ever Dialer PC
<br>

<img src="https://raw.githubusercontent.com/hari161008/Website-For-Everlasting-Android-Tweak/main/Ever%20Dialer/Assets/Banner%20and%20Icon/Ever%20Dialer%20Banner.png" width="100%" />
Ever Dialer PC is the ultimate desktop companion for <a href="https://github.com/hari161008/Ever-Dialer">Ever Dialer</a> on Android! Built natively with Flutter & Dart for <b>Windows 10/11</b> and <b>Linux (Fedora, Ubuntu, Debian, Arch)</b>, it seamlessly connects to your phone over wireless Bluetooth to sync your Contacts, Call Logs, SMS Conversations, Notes, and Live Telemetry in real time. It features full Material You (Material 3) design with dynamic color syncing directly from your phone's wallpaper, turns your PC into a high-fidelity wireless Bluetooth media speaker (A2DP Audio Sink) for calls and music, allows you to send SMS and place calls via Dual SIM directly from your computer, has an interactive smart T9 dialpad, window transparency glass effects, custom typography, NO ADS, zero cloud dependency, and IT's 100% FREEEE & OPEN SOURCE !!!!
<br><br>
<b>Note:</b> To enable wireless synchronization and desktop calling, make sure Bluetooth is enabled on both your PC and Android device, and toggle <b>"Bluetooth Connection & Sync"</b> inside the app. For Linux, PipeWire or PulseAudio with BlueZ is supported out-of-the-box. For Windows, native Core Audio and WinRT Bluetooth subsystems are utilized.

# Features of Ever Dialer PC .✦ ݁˖

### 1. 💻 Cross-Platform Native Desktop Architecture <br><br>
1. 🐧 **Universal Linux Distribution Support** – Built and packaged natively for Fedora, Ubuntu, Debian, Arch Linux, Manjaro, openSUSE, and other modern distributions.
2. 🪟 **Native Windows 10 & 11 Support** – High-performance native Win32/WinRT application executable optimized for modern 64-bit Windows installations.
3. ⚡ **Lightweight Flutter & Dart Core** – Smooth 60/120 FPS desktop rendering pipeline with low CPU and memory footprint.
4. 🖼️ **Frameless Modern Window with Custom Resize Frame** – Clean edge-to-edge frameless aesthetic featuring interactive custom resize boundaries with visual cursors for North, South, East, West, and corner dragging.
5. 🖐️ **Fluid Window Dragging & Double-Tap Maximize** – Smooth window title bar dragging (`WindowDragArea`) with double-tap gesture to maximize, restore, or tile windows.
6. 🎛️ **Native Window Header Controls** – Sleek embedded window minimize, maximize/restore, and close buttons seamlessly integrated into the Material 3 app bar.
7. 💾 **Shared Dual-Boot Disk Compatibility** – Built-in self-healing scripts (`heal.sh`, `heal.bat`, `sync_platform.dart`) for seamless cross-compilation across shared NTFS partitions between Windows and Linux.

### 2. 📱 Wireless Bluetooth Phone Sync Engine <br><br>
8. 🔄 **Zero-Cloud Local Bluetooth Sync** – Directly links PC and Android phone over local Bluetooth RFCOMM sockets; zero servers, zero accounts, and zero internet dependency.
9. 📡 **Background RFCOMM Daemon Architecture** – Resilient background Python daemon (`bt_sync_daemon.py`) and native controllers managing persistent RFCOMM communication channels.
10. ⚡ **One-Toggle Unified Bluetooth & Sync Activation** – Toggle "Bluetooth Connection & Sync" once to automatically power on Bluetooth, configure discovery, and launch data synchronization.
11. 🔍 **Automatic Broadcast & Pairability** – Automatically sets desktop Bluetooth alias to **"Ever Dialer PC"** and configures discoverability without timeouts for hassle-free pairing.
12. 📋 **One-Tap Desktop Bluetooth Alias Copy** – Quickly copy your PC's Bluetooth broadcast name to clipboard with one click from the setup card.
13. 📱 **Real-Time Device Handshake & Status Detection** – Instantly detects phone connection state, displaying paired device name, MAC address, and active streaming badges.
14. 💾 **Multi-Tier Local Offline Cache** – Caches contacts, call logs, SMS threads, and notes in persistent local desktop storage (`shared_preferences`) so your data is instantly accessible even when disconnected.
15. 🧹 **Safe Phone Data Segregation** – Automatically detects when a different phone connects and cleanly manages distinct device cache profiles without data contamination.

# For those who are wondering how Rate and Review works

1. Create a Google form (with sign in required - to prevent multiple reviews and easily editable)
2. Link the Google form with sheets (Name it as Original form)
3. Create another Google form and name it as Website and link all the columns except the gmail column with the Original form (This is because the original form contains G-mail, which is not supposed to be exposed)
4. Linking is easy, just make the original form to be visible to everyone temperorarly, share the link to AI and ask AI to give the code to link it in the another sheet (This will make the Website form to be automatically updated based on the changes in the original form)
5. It will give you the code, and paste it there
6. Then in the website form, click file > share > publish it on web > publish it as CSV > Publish.
7. Now the Link form the website works a backend raw data
8. If you want to have replies to your website, create a new column in the Website form as replies and type your replies to the respective people who you wanted to.
